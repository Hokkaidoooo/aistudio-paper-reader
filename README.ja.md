# AI Studio リーダー

[简体中文](README.md) · [English](README.en.md) · [Español](README.es.md) · **日本語**

Google AI Studio の長い回答を読みやすくし、選んだ質問と回答の 1 組を Typora や Obsidian 向けの Markdown で保存する拡張機能です。画面の表示は中国語です。

## インストールと更新

1. [Releases](https://github.com/Hokkaidoooo/aistudio-paper-reader/releases/latest) から ZIP をダウンロードし、移動せずに使えるフォルダーに展開します。
2. Chrome または Edge で `chrome://extensions` または `edge://extensions` を開き、開発者モードを有効にします。展開済みの拡張機能を読み込む操作で、`manifest.json` があるフォルダーを選びます。リポジトリの [`extension` フォルダー](extension)も直接読み込めます。
3. 旧版の Tampermonkey スクリプト **AI Studio 纸间阅读** を使っている場合は無効にします。未保存の下書きを保存してから AI Studio のページを更新してください。拡張機能の更新時は、ファイルを差し替え、管理画面で再読み込みしてから AI Studio のページを更新します。

## 閲覧とノートの保存

- ページの **阅读**（読む）ボタンかツールバーのアイコンを押します。4 種類のテーマから選び、文字や行間、行幅、コードの折り返しを調整できます。**恢复原版** で元の画面に戻ります。
- **记录问答**（質問と回答を記録）で 1 組を選び、タイトル、タグ、Markdown を確認します。**选择位置并保存**（保存先を選択）または **下载 Markdown**（ダウンロード）を押します。
- 見出し、リンク、リスト、コード、表、および LaTeX ソースを取得できる数式に対応します。取得できなかった項目はパネルに表示されます。表全体を取得できない場合は抽出を止め、元の下書きを保持します。旧版の出力に表が欠けている場合は、元の回答から記録し直してください。
- Markdown ノートには既定で会話リンクが付きます。不要なら外せます。ブログ用の下書きは既定でリンクを含まず、`draft: true` が付きます。

## 権限とプライバシー

拡張機能が要求する権限は、表示設定を保存する `storage` のみです。コンテンツスクリプトの実行先は `aistudio.google.com` に限られ、リーダーは会話ページに表示されます。拡張機能自体はネットワーク通信やモデル API の呼び出しを行いません。保存、ダウンロード、コピーは操作したときに実行されます。下書きはページ内のメモリーにあり、パネルを閉じても残りますが、ページを更新したり閉じたりする前に保存してください。

## 旧版で保存した引用リンクを修正する

Node.js 22 以降を使用します。リポジトリのルートで、例のパスを元のノートと新規の出力ファイルに置き換えて実行します。

```powershell
npm ci
npm run repair:citations -- "note.md" "note-repaired.md"
```

引用リンクの外側でエスケープされた角括弧だけを修正し、元のファイル、コード、数式は変更しません。`npm run build` で拡張機能の ZIP と SHA-256 チェックサムが `dist` に出力されます。
