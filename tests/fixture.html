把阅读的节奏，交还给自己

阅读并不只是把文字映入眼睛。我们会在句子之间停顿，在段落之间整理信息，再把新的内容接到已有的理解上。好的排版，为这些细小的动作留下空间。

一段回答越长，层次、留白与稳定的行宽就越重要。与其让所有文字争夺注意力，不如把最值得停下来的地方清楚地标出来。

01　先让眼睛找到落点

标题告诉你现在在哪里，段落之间的空隙让你有机会稍作停顿。适中的行宽减少横向寻找下一行的距离；舒展的行距则让上下两行不容易混在一起。

读得舒服，不必一次读得更多。能够轻松回到刚才的位置，已经是一种很好的阅读体验。

02　让不同信息拥有自己的形状

  • 观点用短段落表达，一段围绕一个意思展开。
  • 步骤用顺序列表组织，让动作的先后更清楚。
  • 比较交给表格，减少在几段文字之间来回寻找。

03　代码也可以轻一点

代码保持等宽字体和原有缩进。长行默认横向滚动，也可以在阅读设置里打开「长代码自动折行」。行内标记，例如 line-height，与正文自然衔接。

Code
function readingRhythm(paragraphs) {
    return paragraphs.map((text, index) => ({
        order: index + 1,
        text,
        pause: '留一点空间，再读下一段。'
    }));
}

慢一点，也是一种有效率

看到密集的信息时，可以先浏览标题，再选择最需要的段落。阅读设置没有唯一答案，找到与你的屏幕、环境和习惯相合的组合就好。
